# Evaluation 层 · 索引

> 本目录是「AutoGrader Expert」专家智能体包的 **Evaluation 层**（五件套之五）——
> 用**教师金标准**给智能体的产出打分，并把「AI 靠不靠谱」变成一页可复算的数据结论。
>
> **本层不参与 Expert 的运行时**：它不产出评阅结果，也不出现在教师的对话里。
> 它是**开发期与 CI 的确定性能力**，由平台内置 `Bash` 调起（与 Tools 层同一调用通道）。

同级目录（`../`）：`agent/`（Prompt）、`skills/`（方法论）、`tools/`（确定性工具）、`workflow/`（编排）。

---

## 一、目录结构

```
agents/evaluations/
├── README.md                       # 本文件：索引 + 用法 + 完成判据对照
├── metrics.md                      # ✅ 指标定义（**口径真源**，只在这里定义一次）
├── scripts/
│   ├── evaluate.py                 # ✅ 评测脚本：一条命令跑完全部指标
│   └── regression_gate.py          # ✅ 回归门禁：劣化即退出码 1
└── baselines/
    ├── 2026-09-26.json             # ✅ 当前基线（机器可读指标）
    └── 2026-09-26.report.md        # ✅ 当前基线的人读报告
```

## 二、怎么跑

```bash
cd backend/autograder-expert/agents/evaluations

# ① 自测（确定性断言，应全部通过、退出码 0）
python3 scripts/evaluate.py --self-test          # 17 项
python3 scripts/regression_gate.py --self-test   # 10 项

# ② 一条命令出评测报告（同时产出机器可读 JSON 与人读 Markdown）
python3 scripts/evaluate.py \
  --results ../../../../web/public/results \
  --gold /path/to/教师金标准/manifest.json \
  --out  baselines/2026-09-26.json \
  --report baselines/2026-09-26.report.md

# ③ 回归门禁（CI 只看退出码：0 通过 / 1 劣化 / 3 判定不完整）
python3 scripts/regression_gate.py \
  --baseline baselines/2026-09-26.json \
  --current  baselines/<新版本>.json --text
```

**退出码约定（与 Tools 层全局一致）**：`0` 正常 ｜ `1` 需注意（评测：有缺失/无效份；门禁：有劣化）
｜ `2` 输入不可读或非法 ｜ `3` 降级（校验跑不全 → **不给终局裁决**，CI 视为不通过）。

## 三、四个指标速查

> 完整口径（公式、可比性规则、阈值来源、复算方法）**只在 [`metrics.md`](./metrics.md) 定义一次**，
> 此处仅列出方向，不得作为口径依据。

| 指标 | 方向 | 一句话 |
|---|---|---|
| 总分 MAE | 越小越好 | Σ\|AI 总分 − 金标准分\| ÷ 可比份数；另出**按难度档分组**视图 |
| 逐项命中率 | 越大越好 | 12 行明细：该项「档位完全一致」的比例 |
| 档位一致率 | 越大越好 | 上者的**总体汇总值**（同口径，非独立口径） |
| 置信度校准 | ECE 越小越好 | 按契约 §八 的 0.60 / 0.80 分桶，给校准差与 ECE |

## 四、完成判据对照（对应《步骤路径规划书》1.5）

| 规划书步骤 | 完成判据 | 本轮证据 |
|---|---|---|
| **1.5.1 指标定义** | **每个指标都可由原始数据复算** | `metrics.md` 逐指标给公式与可比性规则；`evaluate.py` 的 17 项自测含**逐值断言**（MAE / 命中率 / 一致率 / 分桶 / ECE）；实测报告 `baselines/2026-09-26.report.md` 可由 `--regenerate` 重跑复现（纯函数、无时间戳） |
| **1.5.2 评测脚本** | **一条命令出评测报告** | 见 §二 ②：一条命令同时产出 `2026-09-26.json`（机器可读）+ `2026-09-26.report.md`（人读） |
| **1.5.3 回归门禁** | **门禁可自动判定通过/不通过**；新版本指标劣化即回退 | `regression_gate.py` 以**退出码**判定；本轮实测三种情形：基线对自己 → `0` 通过；人为劣化三项 → `1`（三项均标 `REGRESSED`）；`--tolerance 0.5` → 波动被吸收 → `0`。**该脚本的 10 项自测**覆盖「劣化 / 改进 / 容差吸收 / 缺指标 → 3 / 劣化+缺指标 → 1 且保留 skipped」 |

## 六、边界（本层不做的事）

- **不产生评阅结果**：本层只做「比对与统计」，不改写任何判定（与 S5「不得改写判断内容」同源）
- **不引入规则**：命中判据、分桶阈值全部取自契约与金标准，脚本自身不新增口径
- **不替代教师**：输出的是「一致性数字」，**不是成绩**；差档偏差这类短板**主动披露**，不做美化
- **不参与运行时**：Expert 在对话里不会调用本层；评测结果服务于开发决策、CI 门禁与评审材料

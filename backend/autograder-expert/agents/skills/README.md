# AutoGrader Expert · Skills 索引

> 本目录是「AutoGrader Expert」专家智能体包的 **Skills 层**，共 8 个技能。
> 每个 `.md` 是一份**技能规格**（方法论定义），不是可执行代码。

同级目录（`../`）：`agent/`（Prompt）、`tools/`（确定性能力）、`workflow/`（编排规格）、`evaluations/`（评测）。

---

## 一、三模式与 Skill 落点

教师输入 → `S0` 判断意图 → 分三类模式。三模式分**两组**：

**生产组（决定分数）**

| 模式 | 链路 | 涉及 Skill |
|---|---|---|
| **1 建标** | `T6 给候选样板 → 教师选 → S1 构建 → S5 自检 → 保存` | S1（依赖 T6） |
| **2 评阅** | `S2 解析 → S3 取证与判定 → S4 计算 →〔教师复核〕→ S6 评语 → 输出` | S2 / S3 / S4 / S6（+ S5 横向） |

**消费组（只读，不改任何判定）**

| 模式 | 链路 | 涉及 Skill |
|---|---|---|
| **3 复核** | `已有 ReviewResult → S7 入口 B 解释回放 → 无后置` | S7（入口 B） |

三条补充规则：

- `S5 结构装配与自检` **横向贯穿模式 2** 全链，对内对应 Reviewer 环，**不对教师暴露**
- `S7 入口 A（复核清单）` 服务于**模式 2 内**的教师复核节点；教师若参与，终判分**回灌 S4 重算**，再进 S6
- `S7 入口 B（解释回放）` 服务于**模式 3**：**只读、不改判定、不产生新结果、无后置**

> ⚠️ `S0` 的路由规格**尚未扩展到三模式**（当前仍按两条任务链路由）。
> 缺口与状态见《项目总纲与同步状态.md》第五节「三模式实现状态」。

## 三、依赖关系速查

| 关系 | 内容 |
|---|---|
| 主链 | `S0 → S2 → S3 → S4 → S6` |
| 侧入 | `S1`（Rubric）→ 作为 `S3` 的输入之一 |

## 四、每个技能文件的结构

统一七段，顺序固定：

1. **元信息表** — Skill ID / 所属任务链 / 对内 Agent / 对外名称 / 依赖 Tool
2. **目标**
3. **输入**
4. **输出**
5. **执行规则** — 编号列表，含该技能的硬约束与禁区
6. **常见失败场景**
7. **依赖关系** — 前置 / 后置 / 是否经 S5 校验 / 依赖 Tool

> **多入口技能**（如 `S7`）在「输入 / 输出 / 执行规则 / 常见失败场景」四处按入口分块书写，
> 但七段的顺序与命名不变。

## 五、口径纪律

总分口径、权重序列与「待复核项处理规则」**只在 `S4-score-calculator.md` 中定义一次**。
本目录其他文件一律**不得自行复述或改写**这两项口径，需要引用时指向 S4。
（理由：同一口径写 8 遍，日后改一处会漏七处。）

口径的最终真源见项目根目录的《项目总纲与同步状态.md》第四节「硬约束与核心口径」。

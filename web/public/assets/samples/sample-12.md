## 1 实验目的

了解排序算法。

## 2 实验原理

排序就是把一组数从小到大排好。排序的算法有很多种，冒泡、快排、归并这些都差不多，都是比较大小然后换位置，复杂度大概是 O(n) 到 O(n²) 之间，具体多少要看数据。

冒泡排序是两层循环，外层控制趟数，内层两两比较交换。快排是分治，选一个基准把数组分成两半。归并是先拆开再合并。这几种的具体写法我没仔细看，Python 里面有现成的 sort 可以直接用，我觉得会用就可以了，自己写也写不出更快的效果。

时间复杂度这个概念是说随着数据量变大，耗时会按什么规律增长。O(n) 是线性增长，数据翻倍时间也翻倍，O(n²) 是平方增长，数据翻倍时间变四倍，所以平方的算法在数据多的时候会慢很多。这次用 Python 自带的排序，应该是最快的那种。

## 3 实验环境

- 操作系统：Ubuntu
- 语言：Python

## 4 实验步骤

1. 写一个排序的脚本，先随机生成一万个整数放进列表里。
2. 用 Python 自带的排序排一遍，用 time 记一下前后时间。
3. 运行看输出的时间。

## 5 核心代码

```python
import time
import random

n = 10000
a = [random.randint(0, 100000) for i in range(n)]

t = time.time()
a.sort()
print("sort time:", time.time() - t)

t = time.time()
sorted(a)
print("sorted time:", time.time() - t)
```

## 6 结果

运行之后输出了两个时间，第二个比第一个小一些，因为第二次排的时候数据已经是有序的了。程序没有报错。

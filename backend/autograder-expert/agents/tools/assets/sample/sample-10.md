## 1 实验目的

1. 实现冒泡排序、选择排序与快速排序三种算法，掌握各自的实现思路与代码写法。
2. 在不同数据规模下测量三种算法的运行时间，比较它们的快慢。
3. 通过实验数据验证不同时间复杂度在实际运行中的差异。

## 2 实验原理

冒泡排序通过相邻元素两两比较并交换，把最大的元素逐步"浮"到末尾，时间复杂度是 O(n²)。选择排序每趟在未排序部分选出最小元素放到已排序部分末尾，时间复杂度也是 O(n²)，但交换次数比冒泡少。快速排序采用分治思想，选取一个基准元素把数组分成两段，再对两段递归排序，平均时间复杂度是 O(n log n)，最坏情况下会退化到 O(n²)。三者的空间复杂度分别是 O(1)、O(1)、O(log n)（递归栈）。

三种算法在稳定性上也有区别。稳定性指的是排序前后相等元素的相对顺序是否保持不变。冒泡排序在比较时只在前者严格大于后者时才交换，相等时不交换，因此是稳定的。选择排序需要把找到的最小元素与当前位置交换，这个交换可能跨越多个位置，会把原本在前面的相等元素换到后面去，因此是不稳定的。快速排序在分区过程中同样存在跨距离的元素搬移，因此也是不稳定的。本次实验使用的是随机整数数组，相等元素较少，稳定性差异不会体现在运行结果上。

另外需要说明最坏情况是如何产生的。快速排序每次划分后，如果基准元素恰好是当前区间的最大值或最小值，那么划分出来的两段中有一段长度为 0，另一段长度为 n-1，递归深度就变成 n 层，总比较次数退化为 n² 量级。当输入数组已经有序、而基准又固定取区间第一个元素时，就会出现这种最坏情况。本次实验使用随机生成的数组，基准取区间首元素，因此没有触发最坏情况。

## 5 核心代码

```c
#include <stdio.h>
#include <stdlib.h>
#include <time.h>

void maopao(int a[], int n) {
    for (int i = 0; i < n - 1; i++)
        for (int j = 0; j < n - 1 - i; j++)
            if (a[j] > a[j+1]) {
                int t = a[j]; a[j] = a[j+1]; a[j+1] = t;
            }
}

void xuanze(int a[], int n) {
    for (int i = 0; i < n - 1; i++) {
        int m = i;
        for (int j = i + 1; j < n; j++)
            if (a[j] < a[m]) m = j;
        int t = a[i]; a[i] = a[m]; a[m] = t;
    }
}

void kuaisu(int a[], int l, int r) {
    if (l >= r) return;
    int i = l, j = r, p = a[l];
    while (i < j) {
        while (i < j && a[j] >= p) j--;
        a[i] = a[j];
        while (i < j && a[i] <= p) i++;
        a[j] = a[i];
    }
    a[i] = p;
    kuaisu(a, l, i - 1);
    kuaisu(a, i + 1, r);
}

int main(int argc, char *argv[]) {
    int n = atoi(argv[1]);
    int *b = malloc(n * sizeof(int));
    int *c = malloc(n * sizeof(int));
    srand(20260920);
    for (int i = 0; i < n; i++) b[i] = rand() % 100000;

    clock_t t;
    for (int k = 0; k < 3; k++) {
        for (int i = 0; i < n; i++) c[i] = b[i];
        t = clock();
        kuaisu(c, 0, n - 1);
        printf("quick  n=%d  %.4f s\n", n, (double)(clock()-t)/CLOCKS_PER_SEC);
    }
    free(b);
    free(c);
    return 0;
}
```

## 7 结果分析

从表 6-1 可以看出，三种算法里快速排序是最快的，冒泡排序是最慢的，选择排序在中间。规模为 20000 的时候，冒泡用了 1.2188 秒，选择用了 0.8302 秒，快速只用了 0.0052 秒。数据规模变大之后三种算法的耗时都增加了，冒泡和选择增加得比较明显，快速增加得不明显。规模从 10000 到 20000 的时候，冒泡的耗时增加了大约 4 倍，快速增加了大约 2 倍多一点。总体来看快速排序优势很大，在数据量大的时候尤其明显。

## 8 问题与总结

实验中遇到过数组越界的问题，快排递归的时候下标算错了，会访问到数组外面去，后来把递归的边界条件改对之后就正常了。另外一开始没有用固定随机种子，导致每次生成的数据不一样，结果波动比较大，加上 `srand` 固定种子之后数据稳定了。

本次实验完成了三种排序算法的实现与性能对比，快速排序明显快于另外两种，这与课本上讲的复杂度结论是一致的。基本达到了实验要求，后面可以再补充更多数据规模和其他排序算法。

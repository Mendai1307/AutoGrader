# W3 · 失败处理与重试路径

> 对应《步骤路径规划书》**1.4.3**：任一环失败的回退与重试路径，**失败不中断全流程，有明确状态标记**。
>
> 一条前置纪律：**失败要显式，不要漂亮**。「未解析」不得写成「缺失」，「没跑全」不得写成「通过」。

---

## 一、三条不可让步的原则

| # | 原则 | 含义 |
|---|---|---|
| **F1** | **失败不中断整链** | 某一环出问题，其余环仍应产出可交付的部分结果；**但必须显式标记**，不得静默跳过 |
| **F2** | **重试只改结构，不改判断** | 重试的输入是**错误清单**（T5 的 `errors[].code` / `jsonPath` / `fixHint`），目标是让产物**合规**；**不得借重试之名改写评分内容** |
| **F3** | **限定轮次，仍败即停** | 重试有上限；到上限仍不合规 → 标记「待人工」。**不得降级放行**，也**不得无限重试**耗尽预算 |

## 二、状态标记词汇表（闭环，不得自造）

| 标记 | 出现位置 | 含义 |
|---|---|---|
| `ok` / `partial` / `failed` | T1 的 `status` | 「跑完 / 部分跑完（有未解析位置）/ 完全没跑出来」 |
| `pass` / `fail` / `skipped` | 契约 `selfCheck.{schema,recompute,fingerprint}` | T5 六项检查的逐项结论 |
| `ok` / `errors` / `degraded` / `errors-degraded` | T5 的 `exitReason` | 全通过 / 有错 / 校验没跑全 / 两者并存 |
| `draft` / `confirmed` | 契约 `reviewMeta.status` | **建议态 / 教师已确认**（生效态的判定权在教师，不在 AI） |
| `pending = true` | `scores[]` | 尚无终值 → **不计入总分求和**，计入 `W_r` |
| `needsReview = true` | `scores[]` | 需要教师看一眼 → **不影响总分**（与 `pending` 语义正交，不得互相替代） |
| `teacher-participated` / `ai-only` | 契约 `reviewMeta.mode` | 教师是否参与过复核 |
| **待人工** | Reviewer 环的终态标记 | 限定轮次后仍不合规；**这是合法终态，不是失败遮羞布** |

## 三、逐环失败路径

| 环 | 失败模式 | 怎么处置 | 落到哪个标记 |
|---|---|---|---|
| **1 Parser** | 无文字层（扫描件）/ 结构未识别（有正文无标题）/ 不支持格式 / 文件不可读 | 输出**结构化失败**；**不得报「缺失」**、不得硬猜内容；把未解析位置逐个列进 `failures[]` | `status = partial`（T1 退出码 1）或 `failed`（退出码 2）；`failures[].reason` |
| **2 Evidence** | 某评分点找不到证据 | 写「**未找到**」+ 降置信 + 标待复核；**不得推断为「没做」** | `evidence: []` + `needsReview = true`（契约级要求：证据为空时该项 `needsReview` 必须为 true）+ `doubts[]` |
| **2 Evidence** | T3 判为无效引用（`anchor-not-found` / `block-ref-not-found` / `quote-mismatch` / `no-locator`）或**歧义命中** | 该证据**作废**；换坐标重取，或降置信 / 标待复核；**歧义必须人工确认落点** | `rejected[]` 项一律不进 `evidence[]`；T3 退出码 1 = 「需注意」 |
| **2 Evidence** | T2 报告自相矛盾（`blocks` 与 `summary` 不一致） | **停下来报错**——报告不可信，不得继续在其上做判定 | T2 退出码 2（结构化报错） |
| **2 Evidence** | 规则集未覆盖某项 | 列入 `notCovered` + `notCoveredReasons`，**不猜** | T2 退出码 1 |
| **3 Grader** | T4 报输入缺项 / 越界 / 形状不符 | **结构化报错，不出近似值**；补全输入后**重算**（输入变则重算，不得沿用缓存） | T4 退出码 1（`kind = invalid-input`）；`--mode rank` 缺 `confidence` 亦同 |
| **3 Grader** | 教师中途改了某一项 | **重算总分**；不得沿用缓存 | `scores[].score` 更新 → `totalScore` / `total` 重出 |
| **4 Reviewer** | T5 六项中任一项 `fail` | **fail-fast**：按 `errors[]` 清单重试（**限定轮次**）；仍败 → 标「待人工」 | T5 退出码 1；`selfCheck.errors[]` |
| **4 Reviewer** | T5 退出码 **2**（schema 用了不支持的关键字 / `$ref` 不可解析 / 输入畸形） | **停下报错**——这是环境或契约问题，重试无意义 | T5 `kind = schema-error` / `invalid-input` |
| **4 Reviewer** | T5 退出码 **3**（部分校验因依赖缺失被跳过） | **视为不通过**——宁可显式降级，也不假装通过 | `exitReason = degraded` / `errors-degraded`；CI 不通过 |
| **5 Feedback** | 某句话没有证据支撑 | **删掉它**，或改写为「报告中未找到相关内容」；**不得补一句「可能」来掩盖** | 不新增字段；评语本身即产物 |
| **5 Feedback** | 教师未参与复核 | **不是失败**：清单照常生成（不阻塞），直接用 AI 建议分写评语 | `reviewMeta.mode = ai-only`；输出结构**与教师参与时完全一致** |

## 四、回退的边界（能退到哪、不能退到哪）

| 情形 | 可以回退到 | 不可以 |
|---|---|---|
| Parser 失败（未解析） | 报「无法判定章节存在性」并**停止对该维度的判定** | 回退成「章节缺失」——这是**主动的否定断言**，违反 L1 |
| 某处引用被判无效 | 回退到 **Evidence 环重新取证** | 回退到「用一句类似表述顶上」——T3 就是为了堵这条路 |
| 某个数字算错 | 回退到 **Grader 环用 T4 重算** | 回退到「AI 手算一个更合理的数」——所有数字必须由 T4 产出 |
| Reviewer 判定不合规 | 回退到**产出该片段的那一环**修结构 | 回退到「直接改分数让它合规」——**重试只改结构，不改判断** |
| 教师推翻了某判定 | **以教师为准**，不解释、不留异议；差异数据保留在契约层 | 与教师争论，或在产物里留「AI 原本认为……」 |

## 五、与退出码的映射（CI 怎么看）

| 脚本 | 0 | 1 | 2 | 3 |
|---|---|---|---|---|
| T1 文档解析器 | 全部解析成功 | 部分成功（有 `failures`） | 输入不可读 / 完全失败 | — |
| T2 客观核查器 | 正常 | 部分规则未覆盖 | 规则集非法 / 报告自相矛盾 | — |
| T3 引用解析器 | 全部有效且无歧义 | 有无效项或歧义命中 | 输入不可读 / 形状不符 | — |
| T4 确定性计算器 | 正常 | 输入缺项或非法 | 输入文件不可读 / 非法 JSON | — |
| T5 契约校验器 | 六项全通过 | 校验失败（`errors` 非空） | 输入畸形 / schema 不可用 | **降级：有检查被跳过** |

**CI 判定口径**：`0` 通过；`1` 视为不通过（需修）；`2` 停下报错（环境或输入问题）；
**`3` 视为不通过**——它是「没跑全」，不是「跑赢了」。
（T5 的这条纪律是本项目的既定裁决：**校验没跑全时，错误清单本身也不可靠**，所以不给看似终局的裁决。）

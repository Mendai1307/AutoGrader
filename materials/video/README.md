## 台本要点速览

- **形态**：180 秒（3:00）· 1920×1080 · 25 fps · 硬字幕内嵌
- **主线**：7 路由巡礼（`/` → `/agents` → `/grade` → `/report/[id]` → `/upload` → `/eval` → `/trace`）
- **声音**：纯字幕 + BGM，**无旁白**（可选旁白稿见台本 §七）
- **素材**：录屏约 128s（71%）+ AI 生成约 36s（20%）+ 动效转场约 16s（9%）
- **重心**：S4（`/report/[id]`，30s）与 S6（`/eval`，30s）合计占全片 1/3 ——
  一个证明「可审计」，一个证明「可评测」，这两处是评委真正的关注点

## 视觉纪律（与产品 token 一致，不得偏离）

暖灰白纸面 `#F3F0EB` · 近黑正文 `#080A08` · 暖棕**唯一**强调色 `#9B7247` · 暖杏金选中信号 `#C5A16B` ·
赭石 `#8C4A3A` **仅用于真错误**。数据语义一律用**刻度符号 + 字重 + 灰阶**，**不用红绿**。

## 制作路径（依赖顺序）

```
✅ ① 发布线上链接（**已完成**）  →  ② 录制 7 个路由的素材  →  ③ 生成 4 组 AI 画面
                                           ↘
④ 选 BGM 并归档授权  →  ⑤ 剪辑装配  →  ⑥ 过 §九 自检清单  →  ⑦ 出片
```

> **关键顺序约束**：**先把视频录完，再动产品页面**。站点改版会让已录素材作废（台本 §十 P2）。

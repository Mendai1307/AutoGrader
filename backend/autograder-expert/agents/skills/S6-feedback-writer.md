# S6 · 评语生成

| 项 | 内容 |
|---|---|
| Skill ID | S6 |
| 所属任务链 | 流程 B · 环 4 |
| 对内 Agent | Feedback |
| 对外名称 | Feedback Generation |
| 依赖 Tool | — |

## 目标

产出基于证据、可执行、非模板化的评语。

## 输入

- S3 的证据四元组
- S4 的总分与计算明细
- 总分来源二选一：**教师参与复核 → 教师终判分；教师不参与 → AI 建议分**
- 教师选定的措辞档位（中性 / 鼓励 / 严格）

## 输出

- 评语：每条挂回「评分点 + 证据」
- 可执行改进项

## 执行规则

1. 每一句评价性语言必须有证据支撑；无证据的只能写成
   「报告中未找到相关内容」。
2. 不生成涉及学术诚信的表述，不涉及学生个人情况。
3. **不自行定调**：措辞档位由教师选，本 Skill 不替教师决定语气。
4. 两种总分来源走**同一套生成规则、输出结构完全一致**，
   保证教师不参与时不降级。
5. 多份评语之间不出现重复句式，保持非模板化。
6. 评语只描述「事实 + 下一步」，不做人格评价。

## 常见失败场景

- 写成「基本正确，继续努力」这类套话。
- 把没有证据支撑的判断写进评语。
- 教师参与 / 不参与得到两种不同形态的报告。
- 语气自作主张，超出教师选定的档位。
- 对低置信度项给出确定性的负面表述（应改为「本次未确认」这类中性说法）。

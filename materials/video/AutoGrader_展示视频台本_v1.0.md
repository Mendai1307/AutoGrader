# AutoGrader · 作品展示视频台本 v1.0

> **形态**：180 秒 · 7 路由巡礼 · 录屏 + AI 生成画面混剪 · 纯字幕 + BGM（无旁白）
> **用途**：粤港澳大湾区 AI Coding 创新大赛（LearnBuddy 版）· 五件必交之一「3 分钟演示视频」
> **状态**：v1.0 待评审。所有产品事实取自仓库实测结果，未使用任何未经核实的数字。
> **落点**：`materials/video/`（对应《步骤路径规划书》交付物三 · video）

## 〇、一页速览（Production Sheet）

| 项 | 规格 |
|---|---|
| 时长 | **180 秒（3:00）**，不超不欠 |
| 画幅 | **1920 × 1080（16:9）** |
| 帧率 | 25 fps（录屏素材按 60 fps 采，成片降到 25，保证滚动不抖） |
| 交付格式 | MP4 / H.264 / 码率 ≥ 10 Mbps / **硬字幕内嵌**（另附 `.srt` 备用） |
| 响度 | 全片 **-16 LUFS**（BGM 峰值 -6 dBFS，字幕音效 -18 dB） |
| 叙事结构 | 9 场：片头 → 6 个导航路由 + 1 个详情路由 → 片尾 |
| 素材构成 | **录屏约 128 秒（71%）** + **AI 生成画面约 36 秒（20%）** + 动效转场约 16 秒（9%） |
| 声音 | 纯字幕 + BGM + 音效点，**全程无旁白**（可选旁白稿见附录 A） |
| 字幕语言 | 简体中文（术语保留英文原词：ReviewResult / Rubric / Compile-time AI） |

### 视觉色卡（**必须与产品 token 一致**，取自 `web/app/globals.css`）

| 用途 | 色值 | 说明 |
|---|---|---|
| 纸面底 | `#F3F0EB` | 全片主底色，AI 生成画面同样用这个暖灰白，**不要用深色背景** |
| 卡片面 | `#FAF8F4` | 比底色亮一档 |
| 正文 | `#080A08` | 近黑 |
| 辅助文字 | `#77756D` | 暖灰 |
| 细线 | `#C9C4B9` | 分割 |
| **唯一强调色** | `#9B7247` | 暖棕。链接、当前项、刻度、AI 画面的"发光/流动"元素 |
| 选中信号 | `#C5A16B` | 暖杏金。仅用于"命中/当前" |
| 出错专用 | `#8C4A3A` | 低饱和赭石。**全片只在"复算不一致"这类真错误上出现** |

> ⚠️ **本片一条硬纪律**：数据语义（档位 / 置信度 / 难度档）**不用红绿**，一律用
> **刻度符号（`●●●●`／`●●●○`／`●●○○`／`●○○○`）+ 字重 + 灰阶深浅** 表达。
> 原因：红绿在色觉障碍下不可辨，且引入第二色系会破坏产品的单色调性。
> **AI 生成画面同样受此约束** —— 不要生成蓝紫科技光、霓虹、彩虹渐变。

### 字体

- **中文**：MiSans（站点已裁子集，字幕后期用同款同字重）
- **数字/代码**：等宽数字（`tabular-nums`），保证纵向可比 —— 这是产品的排版纪律，也要延续到字幕上

## 一、视频概述

### 标题方案（三选一）

| # | 标题 | 调性 | 建议 |
|---|---|---|---|
| A | **AutoGrader · 让每一分都有据可查** | 主张型 | ⭐ **推荐**。一句话说清"可审计"这个核心差异点 |
| B | **AI 跑在对话侧，证据留在仓库里** | 技术型 | 适合评委偏技术审阅 |
| C | **AutoGrader 智能评阅平台 · 产品导览** | 中性型 | 最稳，但记忆点弱 |

### 风格定位

**克制、仪器感、证据导向**。不做情绪煽动、不做苦情叙事、不用夸张转场。
画面节奏参考"实验室仪器读数"：数字出现即对齐鼓点，不堆砌特效。

### 目标受众

大赛初评与终评评委（含高校教师、技术评审、产品评审）。
**他们只关心三件事**：① 这东西真的在跑吗；② 结果凭什么可信；③ 有没有超出"套壳调用"的技术含量。

### 一句话立意

> **"AI 跑在 LearnBuddy 里，产品放在浏览器里，证据留在仓库和对话记录里。"**
> —— 这句是仓库 README 的原句，也是全片的逻辑骨架。

### 全片节奏曲线（BGM 五段）

| 段 | 区间 | 音乐形态 | 作用 |
|---|---|---|---|
| T1 | 0:00–0:32 | 低频脉冲 + 单音钢琴，稀疏 | 起势，留白多，让字幕被读清 |
| T2 | 0:32–1:10 | 中速电子，稳定律动入场 | 铺陈五件套与工作台 |
| T3 | 1:10–1:40 | 加厚，**指纹复算处留 1 秒空拍** | 峰值①，让"复算一致"被听见 |
| T4 | 1:40–2:32 | 节奏推高，鼓点对齐指标数字 | 峰值②，评测段的证据密度最高 |
| T5 | 2:32–3:00 | 抽走鼓组，回落到钢琴 + 尾音衰减 | 收束，沉淀立意 |

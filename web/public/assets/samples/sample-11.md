## 1 实验目的

1. 学会冒泡排序、选择排序和快速排序的代码写法。
2. 比较三种排序在不同数据量下的运行时间。

## 2 实验原理

冒泡排序是把相邻的两个数比较，小的放前面，一趟下来最小的就到最前面了。选择排序是每一趟找最小的放到前面。快速排序是分治法，先找一个基准，把比它小的放左边大的放右边，然后递归。快速排序的时间复杂度是 O(n log n)，最坏情况也是 O(n log n)，所以它是三种里面最快的。冒泡和选择都是 O(n²)，因为要两层循环。

排序算法还有一些其他的性质。空间复杂度是指排序过程中额外需要多少内存，冒泡和选择都是原地排序，只需要一个临时变量做交换，所以是 O(1)，快速排序因为要递归，递归栈会占用空间，所以是 O(log n)。稳定性是指相等的两个元素排序前后的相对顺序会不会变，冒泡排序是稳定的，选择和快速都不稳定。不过这次实验用的是随机生成的整数，重复的数不多，看不出稳定性的区别。

分治法的思路就是把一个大问题拆成几个小问题，分别解决之后再合起来。快速排序就是典型的例子，它把一个数组拆成两段分别排序，拆到只剩一个元素的时候自然就有序了，然后一路返回就得到了完整的有序数组。归并排序也是分治，不过它是先拆到最小再合并，跟快速排序的顺序相反。

## 5 核心代码

```c
#include <stdio.h>
#include <stdlib.h>
#include <time.h>

// 冒泡排序
void bubble(int a[], int n) {
    for (int i = 0; i < n - 1; i++) {
        for (int j = 0; j < n - 1; j++) {
            if (a[j] > a[j + 1]) {
                int t = a[j]; a[j] = a[j + 1]; a[j + 1] = t;
            }
        }
    }
}

// 选择排序
void select_sort(int a[], int n) {
    for (int i = 0; i < n - 1; i++) {
        int m = i;
        for (int j = i + 1; j < n; j++) {
            if (a[j] < a[i]) m = j;
        }
        int t = a[i]; a[i] = a[m]; a[m] = t;
    }
}

// 快速排序
void quick(int a[], int l, int r) {
    if (l >= r) return;
    int i = l, j = r, p = a[l];
    while (i < j) {
        while (i < j && a[j] >= p) j--;
        if (i < j) a[i++] = a[j];
        while (i < j && a[i] <= p) i++;
        if (i < j) a[j--] = a[i];
    }
    a[i] = p;
    quick(a, l, i - 1);
    quick(a, i + 1, r);
}

int main(int argc, char *argv[]) {
    int n = atoi(argv[1]);
    int *a = malloc(n * sizeof(int));
    srand(1);
    for (int i = 0; i < n; i++) a[i] = rand() % 10000;
    clock_t t = clock();
    quick(a, 0, n - 1);
    printf("n=%d time=%.4f s\n", n, (double)(clock() - t) / CLOCKS_PER_SEC);
    free(a);
    return 0;
}
```

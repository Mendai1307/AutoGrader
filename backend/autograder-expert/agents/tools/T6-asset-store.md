| 项 | 内容 |
|---|---|
| Tool ID | T6 |
| 名称 | 资产库（`asset-store`） |
| 形态 | 命令行脚本，python3，标准输出 JSON |
| 服务于 | S0 任务识别与路由、S1 Rubric 构建 |
| 调用方式 | 平台内置 `Bash` 工具调起 |
| 打包落点 | `skills/<skill-name>/scripts/` 首选；或插件根 `bin/` |
| 脚本 | [`scripts/asset_store.py`](./scripts/asset_store.py) |

## 职责

按条件检索与存取四类资产，为路由与标准构建提供**确定性**的资产入口。

## 四类资产

| `kind` | 资产 | 读写 |
|---|---|---|
| `template` | Rubric 样板库（内置，开箱可用） | **只读** |
| `rubric` | 教师已保存的 Rubric | **可读可写** |
| `sample` | 样例报告库 | **只读** |
| `gold` | 教师金标准（用于 Evaluation 对照） | **只读** |

> `template` / `sample` / `gold` 三类**只读**，是硬约束——它保护「样板是起点，不是标准」这条边界：
> 教师可以选样板、改样板、另存为 `rubric`，但不能就地改写样板库本身。

## 确定性边界

**做**：按 `id` 精确取；按 `tag` / 前缀 / 精确关键字过滤；列清单与元信息；写入 Rubric。

**绝不做**：

- 推荐「哪个样板更合适」
- 语义相似度检索或模糊排序
- 查不到时用相似项顶替
- 改写任何已有资产

> 本工具只做**确定性匹配**。判断「哪份样板适合这次实验」是 S1 与教师的判断，不是本工具能说的话。

## 输入

| 参数 | 说明 |
|---|---|
| `--op <list\|get\|put>` | 操作 |
| `--kind <template\|rubric\|sample\|gold>` | 资产类别 |
| `--id <id>` | `get` / `put` 时的资产标识。**不得含路径分隔符或 `..`**（防越出 store） |
| `--tag <tag>` | `list` 时的标签过滤（可重复）。**多个 `--tag` 为 AND 语义**：条目标签集合须包含全部给定标签 |
| `--contains <text>` | `list` 时的精确子串过滤 |
| `--from <path>` | `put` 时的源文件（仅 `rubric` 允许）。**扩展名须在 `.json` / `.md` 内** |
| `--store <dir>` | 可选；资产根目录，缺省用随包资产目录（`agents/tools/assets/`） |

## 输出

单个 JSON 对象，随 `op` 变化：

- `list`：`items`，每项含 `id` / `kind` / `title` / `tags` / `ext` / `readOnly` / `digest` / `path`
- `get`：`item`（元信息）+ `content`（正文）
- `put`：`id` / `digest` / `path` / `written`（`kind` 非 `rubric` 时报错退出）

`digest` 为内容摘要指纹，使 S0 / S1 的下游输入可被追溯与复算。

## 退出码与失败

| 码 | 含义 | 下游必须怎么做 |
|---|---|---|
| 0 | 正常 | — |
| 1 | **目录存在但查询未命中**（结果为空） | **明示「查不到」**，不得用相似项顶替；由 S1 转为「新建标准」路径 |
| 2 | 资产根或类别目录**不存在** / 资产非法 / 对只读类别执行 `put` / `--id` 越界 / 源文件扩展名不在白名单 | 结构化报错 |

### ⚠️ 「目录不存在」≠「库为空」（本轮修复）

曾出现：类别目录不存在时 `list_items` 直接 `return []` → **退出码 1（未命中）**。
而退出码 1 的下游动作是「由 S1 转为『新建标准』路径」——
于是**「资产根本没随包」被读成「库里确实没有样板」**，S1 走错分支且无人察觉。

**现行为**：资产根或类别目录不存在 → **退出码 2** + 明确文案
「这不是『库里没有样板』，而是**资产未随包**」。
调用方（S0 / S1）据此可以区分「确实没有」与「环境没装好」。

## 依赖与实现约束

- 禁止网络与 AI 调用；纯函数（`put` 除外，写入幂等：同内容同 `digest` 不重复写）
- 检索一律确定性匹配，**不得引入语义排序**
- 变更 `--store` 后同一查询结果必须可复现
- `--id` 与写入扩展名的约束是**硬约束**：扩展名不在白名单的写入会让文件
  `list` / `get` **都看不见**（只认 `.json` / `.md`），属静默丢数据，必须直接拒绝
- `--self-test` 在无可写临时目录的环境（锁定 CI / 受限沙箱）下返回
  **`kind: "no-writable-temp"` + 退出码 2**，与「断言失败」可区分，不得裸 traceback

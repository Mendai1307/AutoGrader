# 两份 docx 的过期部分 · 裁决清单

> **用途**：按你的指令「docx 文档过期部分发给我裁决」逐条摊开，等你裁决后再改 docx。
> **本回合未改动任何一份 docx。**
> **怎么用**：每条给「原文 / 为什么过期 / 建议改法 / 待裁决选项」。你可以逐条回「编号 + 选项字母」，
> 或直接说「**全部按建议**」。每条的建议都是我推荐的默认值。
> **来源标注**：`[AUDIT]` = AUDIT.md P2-27 已列；`[补]` = 我这轮新发现（AUDIT 未列）。
> **一句话总纲**：两份 docx 是**立项当日**的产物，此后项目在**口径（忽略时间）、范围（模式 4 排外、备用链接废弃）、
> 结构（8 Skill / 6 Tool / 契约冻结 / 六项校验）** 三个维度上都变了。它们现在的定位应当是
> **「立项决策的原始记录」**，不该继续承担「当前口径真源」的角色——真源是 `项目总纲与同步状态.md`。

# S3 · 证据取证与逐点判定

| 项 | 内容 |
|---|---|
| Skill ID | S3 |
| 所属任务链 | 流程 B · 环 2 |
| 对内 Agent | Evidence + Grader（判定段） |
| 对外名称 | Evidence Grading |
| 依赖 Tool | **T2 客观核查器**（统计特征 / 代码 API / 查重线索）、**T3 引用解析器**（逐字引用校验——证据忠实度的**唯一硬闸门**，见 `../tools/T3-citation-resolver.md`） |

## 目标

为每个评分点找到证据，并给出**建议档位与建议分**，形成「证据包 + 疑点清单」。

## 输入

- S2 的报告结构体
- 教师 Rubric
- **教师已给出的任何判断**

## 输出

- 逐评分点四元组：`评分点 → 证据（原文引用 + 坐标）→ 建议档位 / 建议分 → 置信度`
- 疑点清单

## 执行规则

1. **无证据不得给高置信**（硬约束）。找不到证据的写「未找到」，
   **不得推断为「没做」**。
2. 证据必须是原文引用 + 坐标；**不得改写、概括、拼接、润色**。
3. 只输出**建议分**，措辞里不得出现「该生得了 X 分」这类终判表述。
4. **教师已判定的项优先级最高**：直接采用，不重判、不附注、不解释。
5. 证据不足时宁可降置信度，**不得为了把每一项填满而编造理由**。
6. 低置信度项标记为「待复核」，仍然交付（不阻塞），但进入 S4 时不计入总分。

## 常见失败场景

- 编造一条报告里并不存在的缺陷。
- 被「写得漂亮但做错了」的报告骗过：图表齐全、术语准确、结论朗朗上口，但数据对不上。
- 把「未找到证据」写成「学生没有做」。
- 教师已经改过的项又被重判回去。
- 为了凑满每一项的判定，用「类似表述」冒充原文引用。

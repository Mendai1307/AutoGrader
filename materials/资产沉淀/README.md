# AutoGrader 资产沉淀

> 本目录把两代 AutoGrader 项目在 `.learnbuddy/` 里累积下来的**技能、工作流程、试错经验、特定情况处理方法**，
> 从「对话日志形态」落成「可交付、可复核的文档形态」。

## 为什么有这个目录

项目全程以 LearnBuddy 为唯一平台，AI 的推理、决策、踩坑与修正都发生在对话侧，
原始形态是 `.learnbuddy/memory/` 下的每日日志。日志适合**追溯**，不适合**评审时快速取用**。
本目录做的是**形态转换**——只归纳与结构化，不新增结论；每条内容都能在原始记录里定位到出处。

## 内容

| 文件 | 回答什么问题 |
|---|---|
| `01-技能清单.md` | 项目沉淀了哪些可复用的技能（Skills / Tools / 脚本 / 专家） |
| `02-工作流程.md` | 这些技能按什么流程串起来跑（生产、门禁、装配、归档） |
| `03-试错经验.md` | 走过的弯路：现象 → 根因 → 处置 |
| `04-特定情况处理方法.md` | 遇到某类情况该怎么办（可直接照做的处置手册） |

## 来源与口径

- **原始记录**
  - v0.1（`AutoGrader`）：`tencent_cloud_aigc/.learnbuddy/memory/2026-09-20 ~ 09-22.md` + `MEMORY.md`
  - v0.2（`AutoGrader_rebirth`）：`.learnbuddy/memory/2026-09-25.md`、`2026-09-26.md`、`MEMORY.md`、`PROJECT_DETAILS.md`
- **整理时间**：2026-09-26
- **口径**：只做归纳与结构化。文中数字一律**引自原记录中标注为「已实跑核验 / 已独立复现」的值**，
  未实跑核验的推断不在本目录出现。
- **落点提示**：本目录只放**方法与经验**；文件本体（规格、脚本、数据）在
  `backend/autograder-expert/`（交付物一）与 `web/`（交付物二）。
